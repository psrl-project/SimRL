本文记录 [`../blog.md`](../blog.md) 所引用的 10 个框架的具体 commit，以及复核方法，供读者自行核对正文中的源码链接和行号。

## 复核方法

集群环境禁止直接使用 `git clone` 和 GitHub 的 code-search API，但允许通过 `codeload.github.com` 用 `curl` 拉取 tarball：

```bash
mkdir -p /tmp/src && curl -sL \
  https://codeload.github.com/<owner>/<repo>/tar.gz/<commit> | tar xz -C /tmp/src
```

下载后在本地按文件路径和行号核对，比逐文件网页抓取更快也更可靠，不会被网页摘要截断长文件。
